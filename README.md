# Beyond Sosaria Scripts

Free, standalone RazorEnhanced scripts for the Beyond Sosaria shard, written for the TazUO client.

Each script lives in its own repository, with its own instructions, releases and issues. Each is a single file: no
other files to install, and no setup outside the game.

| Script | What it does |
|---|---|
| [Omni Panning](../../../beyond-sosaria-panning) | Pans for gold from town to town and along the shore, unloads at the bank or your own chest, and fills Harry Johnson's Gold Panning Orders. Several characters can run it together without fighting over the same water. |
